🔑 유튜브 검색 키 넣기 (처음 한 번만)

키는 이 휴대폰에만 저장돼요. 하루 약 100번 검색까지 무료예요.

📖 키 만드는 방법 (5분)
  1. 구글 클라우드 · YouTube Data API 열기 → 구글 로그인
  2. 위쪽 「프로젝트 선택」 → 새 프로젝트 (이름: BK레퍼런스) → 만들기
  3. 사용 버튼 누르기
  4. 왼쪽 메뉴 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키
  5. 만든 키 옆 수정 → 🔒 잠금 2가지:
    ① 애플리케이션 제한: 웹사이트 → https://bangkeukryul.github.io/*
    ② API 제한: YouTube Data API v3만 → 저장
  6. 키 복사 → 위 칸에 붙여넣고 저장

⚠️ 키는 카톡 · 메일로 다른 사람에게 보내지 마세요.
